# Politique de sécurité

## Signaler une vulnérabilité

Ouvrir un rapport privé via l'onglet Security du dépôt GitHub
(« Report a vulnerability »). Si ce n'est pas disponible, ouvrir une issue qui
décrit le problème sans détail exploitable et demander un canal privé.

Accusé de réception sous une semaine. Projet maintenu par une seule personne :
aucun SLA au-delà du meilleur effort.

## Périmètre

Le skill lit un dépôt pouvant contenir du code d'intégration de paiement. Ce
qu'il lit, ce qu'il écrit et ce qui ne quitte jamais votre machine est décrit
dans [docs/PRIVACY_AND_SECURITY.md](docs/PRIVACY_AND_SECURITY.md).
